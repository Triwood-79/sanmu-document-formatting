# 隐私与发布边界

## 内容边界

- 格式配置只保存版式参数，不保存姓名、组织、日期、正文、文件路径或输出历史。
- 示例只使用“某单位”“某年某月某日”“示例标题”等虚构占位符。
- 不把业务正文当作需要删除的隐私字段；元数据清理不得改写正文语义。
- 不提供敏感标识或密级字段。

## DOCX 清理

每次输出后运行 `scripts/privacy_scrub.py`，清理作者、最后修改者、公司、管理者、自定义属性、外部模板关系和可安全移除的编辑会话标识。随后运行 `scripts/validate_docx.py`。

## 发布检查

1. 运行 `scripts/privacy_scan.py` 扫描 Skill 文件夹和待发布 ZIP。
2. 另行传入项目特定的禁用词；禁用词本身不要写入 Skill 源码。
3. 排除 `.git`、缓存、日志、用户配置、配置历史、测试输出、真实文档和临时文件。
4. 使用 `scripts/package_skill.py` 生成 ZIP，再次扫描 ZIP 内的文本及 DOCX/XML 内容。
5. 无渲染器时只能报告结构验证通过，不得报告视觉验收通过。
