# 格式字段与执行规则

## 内置预设

- A4 纵向；页边距为上 3.7 cm、下 3.5 cm、左 2.8 cm、右 2.6 cm。
- 全文加粗，包括页码。
- 主标题：方正小标宋_GBK，二号 22 pt，居中、无缩进、固定行距 35 pt，段前 35 pt。
- 一级标题：方正黑体_GBK，三号 16 pt，首行缩进 2 字符、固定行距 30 pt、两端对齐。
- 二级标题：方正楷体_GBK，三号 16 pt，首行缩进 2 字符、固定行距 30 pt、两端对齐。
- 正文：方正仿宋_GBK，三号 16 pt，首行缩进 2 字符、固定行距 30 pt、两端对齐；数字和英文使用 Times New Roman。
- 补充参考资料：仅限整段括号备注或用户明确标注的段落；方正楷体_GBK，小三号 15 pt。
- 说明内容：主标题后的署名/单位行与日期行；方正楷体_GBK，三号 16 pt，居中、无缩进、固定行距 35 pt。
- 标题空行：主标题后必须保留一个独立空段，使用正文段落几何（固定行距、两端对齐、首行缩进），不能仅用主标题段后距模拟。
- 落款：文末单位行和独立日期行使用正文字体、字号和加粗设置；正文结束后空一行，空行、单位和日期共同置于右侧落款区域（左缩进 6160 twips / 28 字符），区域内居中、首行不缩进，固定行距跟随正文。
- 默认双面打印：页码在下方外侧，奇数页右、偶数页左。单面或平板模式改为下方居中。
- 页码：宋体，四号 14 pt，粗体，半角阿拉伯数字，显示为 `— 1 —`。

V1 暂不新建或重构完整的版记结构。已有文档中的印发机关和印发日期行应标记为 `colophon`，仅将中西文字体族统一为正文字体（中文方正仿宋、英文 Times New Roman）并统一为黑色；原字号、粗体、对齐、段距、分隔线和位置保持不变。复杂版记布局仍须提醒用户手动完成。

正文、标题、说明、版记等保留段落、页码及已纳入处理的表格文字，排版后字体颜色统一为黑色。

## 表格规则

- 表格标题：仅在检查阶段确认存在表题时处理，中文字体沿用主标题的方正小标宋预设，英文和数字沿用主标题西文字体，颜色改为黑色，并应用已确认的全局加粗设置；字号、对齐和段落间距保持原样。
- 第一层表头：中文字体沿用一级标题的方正黑体预设，英文和数字沿用一级标题西文字体，颜色改为黑色，并应用全局加粗设置。
- 第二层表头：确认存在第二层表头时，中文字体沿用二级标题的方正楷体预设，英文和数字沿用二级标题西文字体，颜色改为黑色，并应用全局加粗设置。
- 表格正文：中文字体沿用正文的方正仿宋预设，英文和数字沿用正文西文字体，颜色改为黑色，并应用全局加粗设置。
- V1 统一表格字体族、文字颜色和全局加粗设置，不擅自修改字号、对齐、行距、段前段后距、边框、底纹、行高和列宽。
- 检查器默认建议第一行为表头；仅当第一行存在合并单元格，或第二行已标记为重复表头时，建议两层表头。每张表的 `title_paragraph_index` 和 `header_rows` 必须在执行前展示给用户确认，`header_rows` 可为 `0`、`1` 或 `2`。

## 自动识别

- 第一段非空文字为主标题。
- `一、`、`二、` 等开头为一级标题。
- `（一）`、`（二）` 等开头为二级标题。
- 主标题后连续的短署名/单位行和日期行可识别为说明内容；新建文本可用 `[说明]` 明确标记。
- 文末短单位行加独立日期行识别为落款；新建文本可用 `[落款]` 明确标记。落款与含“印发”的版记是不同角色。
- 整段由中英文括号包围的内容可识别为补充参考资料。
- 其他顶层段落为正文。

已有文档必须先显示按段落索引生成的识别结果及每张表的表题候选、表头层数。用户可通过修改分类 JSON 将任一段落改为 `main_title`、`heading1`、`heading2`、`body`、`reference_note`、`description`、`signature`、`colophon` 或 `skip`，并可修改表格的 `title_paragraph_index` 和 `header_rows`。

分类 JSON 默认保留，便于复核和重做。只有用户明确要求删除时，才先运行 `cleanup_classification.py` 做同目录、文件类型、内容结构和哈希校验；展示校验结果并再次获得确认后，才携带该次返回的 SHA-256 执行删除。校验失败或文件发生变化时必须保留文件。

## 修改字段

使用点路径修改草稿，例如：

```powershell
python scripts/profile_manager.py begin
python scripts/profile_manager.py set page.margins_cm.top 4.0
python scripts/profile_manager.py set page.print_mode '"single"'
python scripts/profile_manager.py diff
python scripts/profile_manager.py confirm
```

值按 JSON 解析；字符串需要作为 JSON 字符串传入。只允许修改下列 V1 开放字段。

V1 可修改范围仅包括：页边距、打印模式、全局粗体；主标题/一级标题/二级标题/正文/补充参考资料/说明内容的中英文字体、备用字体、字号、对齐、首行缩进、固定行距和段前距；页码字体、备用字体、字号和粗体。纸张固定为 A4 纵向，页码数字样式、装饰与位置固定，不在 V1 中开放修改。

## 预设问答规则

- 提问新值时同时显示该字段的当前值。
- `重新录入排版格式` 开始前，先用 `profile_manager.py view` 读取并按组展示完整当前值，再创建全新草稿。
- 重新录入时必须逐项确认所有 V1 开放字段；用户回答“保持当前值”时，也要把当前值明确写入全新草稿，避免无意恢复成内置默认值。
- 固定行距必须明确询问，至少分别覆盖：主标题、一级标题、二级标题、正文、补充参考资料和说明内容。用户可以给多个对象一个统一行距，执行时分别写入对应的 `line_spacing_pt` 字段。
- 所有行距以 pt 为单位，并在最终差异中逐项显示“当前值 → 新值”。
